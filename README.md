# 🚀 Data Transformer – SQL Database Project

## 📌 Project Overview
**Data Transformer** is a MySQL-based database project designed to manage and analyze customer information, orders, and employee records.

This project demonstrates practical SQL concepts, including database creation, table relationships, joins, subqueries, date functions, string functions, aggregate functions, window functions, and conditional statements.

## 🎯 Project Objectives
- Create and manage a relational database.
- Store customer, order, and employee information.
- Understand relationships using Primary Keys and Foreign Keys.
- Retrieve meaningful information using SQL queries.
- Perform data transformation and analysis.
- Apply advanced SQL concepts to real-world scenarios.
